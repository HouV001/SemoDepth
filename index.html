(b) Radar-Modulated Selection (RMS). Radar adds modulations to the step size $\boldsymbol{\Delta}_t$ and readout $\mathbf{C}_t$ (teal arrows). The input projection $\mathbf{B}_t$ is computed from the image only (blue arrows), and the state matrix $\mathbf{A}$ never sees radar. The state update block applies zero order hold (ZOH) discretization and the recurrence $\mathbf{h}_t = \bar{\mathbf{A}}_t\mathbf{h}_{t-1} + \bar{\mathbf{B}}_t x_t$. The readout block emits $y_t = \mathbf{C}_t^{\top}\mathbf{h}_t$. All radar projections start at zero, so the block starts as vanilla Mamba.

Abstract

Radar camera depth estimation turns a very sparse but metric radar signal into a dense depth map. Existing methods combine radar and image features outside the sequence operator of the backbone, through concatenation, confidence gating, sparse supervision, or graph based extraction. Mamba variants for multimodal fusion also leave the selection mechanism itself unimodal. We argue that selection is the right place for radar to enter.

We introduce Radar-Modulated Selection (RMS), which injects radar inside the selective scan of Mamba. Radar adds learned perturbations, initialised at zero, to the step size $\boldsymbol{\Delta}$ and the readout $\mathbf{C}$. The input projection $\mathbf{B}$ and the state matrix $\mathbf{A}$ never see radar. At initialisation the block equals a pretrained image Mamba, so radar gains influence only where it improves accuracy. The construction also couples the two modalities at linear cost and falls back to the image backbone when radar is missing.

We deploy RMS in a Multi-View Scan Pyramid (MVSP) that matches the fusion operator to the reach of radar at each scale. On nuScenes, SemoDepth reduces MAE by 34.0%, 29.9%, and 29.9% over the previous best within 50, 70, and 80 m. It also has the lowest single frame latency among methods with a public release (26.8 ms). A feature blend placed before the scan adds no accuracy on top of RMS, which supports the view that selection inside the scan can replace fusion outside it. When twice as many spurious radar returns as true ones are injected, the MAE@80 of SemoDepth rises by 1.4%, against 33.6% for a Mamba baseline that fuses radar before the scan.

Key ideas

1. Radar-Modulated Selection (RMS)

Inside each Mamba block, radar features contribute additive, zero-initialised modulations to the per-token step size Δ (memory horizon) and readout C (what the state emits), while the input projection B and state matrix A never see radar. At step zero the block equals a vanilla Mamba scan, so the pretrained image solution is preserved exactly and radar gradients grow only where they improve accuracy. With A and B unimodal, the model falls back to image behaviour under sparse or missing radar.

2. Multi-View Scan Pyramid (MVSP)

A three-tier decoder matches the fusion operator to radar's reach at each resolution: scene-wide four-direction RMS at the coarsest scales, radar-centred windowed RMS at the mid scale, and constant-cost FiLM at the finest scales. Radar stays active at every level, with scan compute concentrated where radar evidence reaches furthest. MVSP lowers MAE@80 by 18% compared with FiLM at every level.

Robustness to radar corruption

Change in MAE@80 on nuScenes under radar corruption at test time. (a) Spurious returns added, as a share of the true returns. (b) Share of true returns kept. (c) Gaussian noise on the depth of true returns. FusionMamba† is our reimplementation of FusionMamba, which shares supervision, loss, recipe, and parameter budget with SemoDepth but fuses radar before the scan. Both models see identical corrupted inputs. With radar removed entirely, SemoDepth loses 3.3% (against 155% for FusionMamba†) and still beats every published method on nuScenes.
